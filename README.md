● Contact Management System

 A simple C++ console-based mini project to manage contact records. It allows adding, viewing, searching, updating, and deleting contacts. Uses file handling and basic OOP concepts.

● Features

  - Add new contacts
  - View all contacts
  - Search contact by name or phone
  - Update contact details
  - Delete contact
  - Store contact details using file handling
  - Automatically generate contact ID

● Contact Details

Each contact contains:

  - Contact ID
  - Name
  - Phone Number
  - Email
  - Address

● Developed Using

  - C++
  - Object-Oriented Programming
  - File Handling (Text File)
  - STL Vector
● How to Run

  1. Open `main.cpp` in any C++ IDE (e.g., Code::Blocks, Dev-C++, Visual Studio Code).
  2. Compile and run the project.
  3. Follow the on-screen menu to manage contacts.
  4. Contact data is saved automatically in `contacts.txt`.
